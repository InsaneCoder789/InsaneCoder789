## Preface

I am **Rohan Chatterjee**, a full-stack developer interested in the point where thoughtful product work meets dependable engineering. I build user-facing applications, backend systems, and the workflows that hold them together.

My favorite projects are the ones that demand more than a polished demo: clear architecture, deliberate trade-offs, graceful failure, and code another person can confidently continue.

> Build it. Break it. Understand it. Then build it better.
